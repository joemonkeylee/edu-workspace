## 3. 必须先处理的四类脏数据

### 3.1 百度云上传任务配置壳（原 1125 个，已于 2026-10-01 删除）

文件名形如 `xxx.pdf.baiduyun.uploading.cfg`，是百度网盘**上传任务**留下的配置壳（831B~13KB 的二进制任务元数据），**不是下载中断的空壳、也不含任何真实 PDF 内容**。

抽样核验（删除前）：717 个 `.pdf` 壳里 **700 个旁边其实有真实的 `.pdf`**（PDF 已下载好，只是上传任务配置文件没清），仅 17 个是纯孤儿壳，其余是非 PDF 资料的壳。所以删壳**不会动到任何真实文件**。

→ **已处理**：2026-10-01 用 `find . -type f -name '*.baiduyun.uploading.cfg' -delete` 全量删除 1125 个，删除后复核 `*.baiduyun.uploading.cfg` 计数 = 0、真实 PDF 仍 4649 个、退出码 0。源盘腾出约 100+ MB。
→ 扫描阶段这条规则现在可省，但脚本里仍保留 `.cfg` / `.baiduyun*` 后缀跳过逻辑以防后续再有残留。

### 3.2 同名重复（283 组 / 628 个文件）

其中 **104 组是强重复**（文件名 + 父目录名都相同），典型是学而思讲义：

```
更多资料1/学而思初中小四门/初一地理学而思/…/05/【课堂笔记】第5讲中东专题陈哥笔记版.pdf
更多资料1/学而思初中小四门/初一地理学而思/…/资料5.28/资-料/05/【课堂笔记】第5讲中东专题陈哥笔记版.pdf
更多资料1/学而思初中小四门/初一地理学而思/…/资料6.10/资-料/05/【课堂笔记】第5讲中东专题陈哥笔记版.pdf
```

同一份资料被 `05/`、`资料5.28/资-料/05/`、`资料6.10/资-料/05/` 三处各存一份。
→ 复制阶段必须按 **内容 sha256** 去重，只保留第一份。这能省下可观空间，也避免专栏里出现三条一模一样的卡片。

### 3.3 整目录噪声：字帖（552 个）

`初中资料合集/11套电子字帖（小初高）全适用` 整棵树是书法字帖 / 控笔训练 / 描红模板：

→ **需要目录级黑名单**，仅靠文件名关键词不够。

### 3.4 路径里的 emoji 与特殊符号

```
💤 362 次    🐐 59    🌲 59    🔥 21    ✅ 9    • 2399 次
```

如 `更多资料3/💤【孙超老师】初中物理`、`🐐🌲初中七年级上册数学有理数运算每日一练`。

## 4. 「按系列组织」为什么行不通

需求原话是「包括但不局限于 五年高考三年模拟 必刷题等系列」。实测：

| 关键词 | 命中数 |
|---|---|
| 五年高考三年模拟 | **0** |
| 五年中考三年模拟 | **0** |
| 五三 / 5·3 | **0** |
| 必刷题 | 21 ~ 97（口径不同） |

数据源里**根本没有五三系列**。而且「五年高考三年模拟」是高中教辅品牌，与「只关心初中」自相矛盾。
65% 的文件识别不出任何系列，剩下的大头是「同步讲义」这种形态词。

**结论：系列不能作为主分类轴。** 建议走 **科目 → 年级** 两级（用户原话也是这个顺序），系列降级为列表上的一个标签/筛选项。

## 5. 设计

### 5.1 整体分两段，互不阻塞

```
[源盘 WD10JPVT-75]                  [COLORFUL256/source/pdf]        [app 数据库]
        │                                     │                          │
   ①扫描+校正+勾选  ────复制+去重+改名───►  ②已整理的中文目录树  ──入库──►  pdf_book
   （新的管理台页面）                        （科目/年级/源目录/文件）      （复用现有 /pdf/scan/commit）
```

- **①整理** 是新东西（本次要建）。
- **②入库** 现成：`POST /pdf/scan/preview` + `POST /pdf/scan/commit`（`server/src/pdf/routes/pdfScan.ts`），已支持 dry-run 预览、hash 去重、引用式存储、封面生成。

### 5.2 目标目录结构 —— 「源目录」不能丢

```
/Volumes/COLORFUL256/source/pdf/
├── 数学/
│   ├── 七上/
│   │   └── 2026秋《名校学典·计算高手》7上(RJ)/
│   │       ├── 计算高手7上.pdf
│   │       └── 答案.pdf
│   ├── 七下/
│   └── 初中通用/          ← 解析不出上下的落这里
├── 英语/
│   ├── 七上/  七下/  八年级/  九年级/  中考/
├── 物理/   化学/   生物/   地理/   历史/   语文/   政治/
└── _待归类/              ← 科目都识别不出的 1063 个，人工兜底
```

保留「源目录名」这一层的三个理由：

1. **避免同名冲突** —— 283 组重名，不留目录层就要改名。
2. **保留来源可追溯** —— 出问题能回到原盘核对。
3. **让预览页可以按目录批量赋值** —— 这是解决 §2.3 那个 86% 学期缺失的关键，见 5.3。

### 5.3 预览页的核心交互：按目录批量赋值，不是按文件

3341 个文件逐个改学期不现实。但同一源目录下的文件**学期/科目几乎总是一致**的（`2026秋《名校学典·计算高手》7上(RJ)/` 里所有文件都是七上数学）。

所以预览页应是 **目录树 + 内联编辑** 而不是平铺表格：

```
┌─ 目录树（可折叠） ─────────────┬─ 文件清单 ──────────────────────────┐
│ ☑ 更多资料1/7上                 │ ☑ 计算高手7上.pdf        2.1MB      │
│   ☑ 26秋《名校学典…》7上(RJ)    │ ☑ 答案.pdf               0.4MB      │
│   ☐ 学而思初中小四门            │                                    │
│ ☐ 初中资料合集/字帖…  ⚠️噪声    │                                    │
├────────────────────────────────┴────────────────────────────────────┤
│ 选中 12 个目录 / 148 个文件                                          │
│ 科目 [数学 ▾]  学期 [七上 ▾]  系列 [名校学典 ▾]  [应用到选中目录]     │
│ ⚠️ 3 个文件为网盘占位（跳过）  ⚠️ 15 个与其它目录重复（将去重）        │
│ [复制到 COLORFUL256]  [导出 TSV]                                     │
└─────────────────────────────────────────────────────────────────────┘
```

必备能力：

| 能力 | 理由 |
|---|---|
| 目录树勾选 + 全选/反选 | 4649 → 3341 的取舍要看得见 |
| 按目录批量改 科目/学期/系列 | 解决 86% 学期缺失（§2.3） |
| 解析置信度着色 | 低置信度的行要一眼看出来 |
| 重复 / 占位 / 噪声标记 | §3 的三类脏数据在预览里就过滤掉 |
| 改名前后对照 | 复用现有 `PdfScanImport` 的删除线 → 新名 展示 |
| 复制进度（可中断、可续） | 94 GB 复制不能没有反馈 |
| **dry-run / 提交 两段式** | 先看清单，确认后才真的复制 |

### 5.4 专栏在前端怎么呈现（已定）

### P3 入库机制（2026-10-01 调整）

**核心变化：入库默认「拷贝」，不再剪切。** 原因：剪切不可撤销，源盘是唯一原始备份，风险过高。

| 项 | 做法 |
|---|---|
| 搬运方式 | `mode: 'copy'`（**默认**）只复制、保留源文件；`mode: 'move'` 才在入库成功后删源（页面默认不勾，需显式打开） |
| 已迁移识别 | `column_book.sourcePath` 记录**源盘绝对路径**；后端 `loadMigratedMap()` 返回 `sourcePath → {id,title,batchId,at}`，预览页据此给文件打 **已迁移** 徽标、计入「已迁移」计数、支持「只看未迁移」筛选 |
| 幂等去重 | 三重：① `sourcePath`（同源文件重复拷贝直接跳过）② `(rootPath, relPath)` 位置 ③ `fileHash` 内容。重复提交同一批是安全的 |
| 表族 | `column_*`（短雪花 id，`VARCHAR(20)` base62），与 `pdf_*` 完全隔离；DDL 见 `server/prisma/column_module_init.sql` 与 `column_book_sourcepath.sql` |

**新增后端接口**（`server/src/pdf/routes/pdfCollect.ts`，均 admin 权限）：

| 接口 | 作用 |
|---|---|
| `GET /pdf/admin/collect/disk?path=` | 目标盘剩余/总容量（`fs.statfsSync`），用于入库预估「迁移后剩余」 |
| `POST /pdf/admin/collect/fs/stat` | 批量路径体积统计（递归文件数/字节数），删除前的预估 |
| `POST /pdf/admin/collect/fs/delete` | 批量物理删除文件/文件夹，需 `echo='DELETE'`，**路径必须严格位于白名单根目录之内** |
| `POST /pdf/admin/collect/purge` | 一键清空：`column_*` 表 与/或 目标盘 PDF（需 `echo='PURGE'`）；文件部分**只允许作用于专栏目标盘**，不会误清源盘 |
| `POST /pdf/admin/collect/commit` | 增加 `mode: 'copy'|'move'` |

**删除安全守卫**（`guardDeletable` / `isStrictlyInside`，已在真实运行时验证 34 项断言全通过）：

- 白名单根目录 = `PDF_COLLECT_SRC`（源盘）+ `COLUMN_PDF_ROOT`（目标盘），可用 `PDF_COLLECT_ALLOW_ROOTS` 追加
- 拒绝：等于根目录本身、根目录之外的任何路径、`/`、`/Volumes`、`/Users/...`、符号链接
- 同前缀不算在内（`/…/资料2` 不被 `/…/资料` 放行）
- 前端侧：删除前先 `fs/stat` 统计文件数与体积 → 二次确认弹窗列出路径 → 才真正删除
